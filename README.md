# TokenLearned-scCLIP
An implementation of TokenLearner to scCLIP. Submitted as a senior project for CPSC 490.

This project is David Wang's submission for CPSC 490. It implements TokenLearner to scCLIP to replace the patching done in the original paper. This does not include data or pre-run models as a result of space constraints. Data can be found from the original scCLIP.

Original versions of scCLIP are found at the original scCLIP, linked below.

Credits to https://github.com/jsxlei/scCLIP for the scCLIP implementation and https://github.com/ariG23498/TokenLearner for the original TokenLearner implementation.
